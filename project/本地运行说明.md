# 本地跑通（AI 聊天）

## 最重要

**不要**在资源管理器里双击 `frontend/index.html`。  
那样是 `file://` 打开，游戏能玩，但 AI 很容易连不上后端。

## 推荐方式（一键）

1. 确认 `backend/.env` 里已填写 `API_KEY`（可从 `.env.example` 复制后改）
2. 双击 **`project/启动本地.bat`**
3. 浏览器会自动打开：**http://127.0.0.1:8080**
4. 点右下角 **AI** 发消息测试

## 手动方式

```powershell
cd g:\plane_ticket\project\backend
npm install
node server.js
```

浏览器访问：**http://127.0.0.1:8080**

## 自检

- 打开：http://127.0.0.1:8080/api/health  
  应看到 `"hasApiKey": true`
- 若 AI 仍报错：按 `Ctrl+F5` 强刷页面
